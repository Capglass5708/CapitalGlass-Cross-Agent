# Intake

Temporary staging area for raw Cursor, ChatGPT, or agent text before it is distilled into the ledger.

## Rule

Do not leave raw material here as the final record.

After distillation, move the valuable information into:

- `work-progress/ACTIVE_WORK.md`
- the relevant file under `work-progress/projects/`
- `verification/`
- `handoffs/`
- `decisions/`

Do not store secrets, database dumps, full source code, copied Bibles, or long raw logs.
